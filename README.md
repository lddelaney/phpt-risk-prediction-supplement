This repository contains the supplemental content for the manuscript “Predicting the Risks of Untreated Primary Hyperparathyroidism and Parathyroidectomy to Inform and Individualize Treatment Decisions.”

The repository includes one file, Supplemental Online Content.docx, containing the supplementary tables referenced in the manuscript.

The companion [PHPT risk calculator](https://endocrinesurgerytools-phpt-risk-calculator.share.connect.posit.cloud/) provides individualized estimates of fracture, kidney function decline, and selected postoperative complication risks.
